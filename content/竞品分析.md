# 竞品分析

## 竞品1: morsecode.world（第一名，155K/mo）

**KE 数据**: 页面流量 155.5K/mo，整站 190.8K/mo，关键词 15.69K

**页面结构（site: 搜索）**:
- `/` — 首页
- `/international/` — 国际莫尔斯电码（含 translator.html）
- `/american/` — 美国莫尔斯电码
- `/shop/` — 商店（卖什么？可能是实体电键/练习器）
- `/news/` — 莫尔斯电码新闻
- `/faq.html` — FAQ
- `/alphabet.html` — 音标字母表
- `/SOS.html` — SOS 专题页
- `/Titanic.html` — 泰坦尼克号与莫尔斯电码（历史故事）
- `/keys.html` — 电键设备介绍

**分析**:
- 老牌站，内容覆盖广（历史、设备、新闻）
- 有实物商店（affiliate 或自营？）
- 技术风格老旧（.html 后缀、传统结构）
- 强项：内容深度、权威性
- 弱项：设计老旧、移动端可能差、SEO 标题不够优化

## 竞品对比总览

| 维度 | morsecode.world | morsecodeapp.com | morse-codetranslator.com | 我们的机会 |
|------|----------------|-----------------|------------------------|-----------|
| 流量 | 155K/mo | ~0 | ~0 | 只有一个真正强的竞品 |
| 页面数 | 10+ | 6 | 8 | 做 15+ 页面即可超越 #2/#3 |
| 工具功能 | 翻译器 | 翻译器 | 翻译+测验 | 翻译+生成+解码+音频+纹身 |
| 内容深度 | 高（历史/设备） | 中（学习文章） | 低 | 场景化内容（纹身/首饰/短语） |
| 设计 | 老旧 | 现代 | 中等 | 现代 + 暗色模式 + 移动优先 |
| SEO | 一般 | 好 | 好 | 每页精准匹配搜索意图 |
| 互动性 | 无 | 无 | Quiz | 练习+Quiz+音频播放 |
| 变现 | 商店 | 无 | 广告 | 广告 + Affiliate |

## 我们的差异化策略

1. **功能覆盖最全**: 翻译 + 生成 + 解码 + 音频 + 纹身生成器 + 练习
2. **场景化内容**: 不只做工具，做用户场景（纹身设计、首饰含义、游戏解谜）
3. **现代体验**: morsecode.world 设计老旧是最大弱点
4. **SEO 矩阵**: 15+ 页精准覆盖长尾词，#2/#3 只有 6-8 页

## 关键发现

- 真正的竞争只有 morsecode.world 一家，其余站流量接近 0
- morsecodeapp.com 的 `/learn/i-love-you-morse-code` 页面排在了 "morse code i love you" 首页——证明做场景化短语页是有效的
- 没有任何竞品做了 tattoo generator 功能——这是空白
- 没有竞品做 affiliate 推荐首饰——变现空白
- morsecode.world 有 `/shop/` 说明这个品类有实物变现空间
