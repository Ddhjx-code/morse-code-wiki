## 站点结构

```
/                          → 首页: Morse Code Translator (核心工具)
/alphabet                  → 字母表 A-Z + 数字
/chart                     → 可打印图表 + PDF
/generator                 → 文字→莫尔斯生成器
/decoder                   → 莫尔斯→文字解码器
/audio                     → 音频翻译器(播放+识别)
/numbers                   → 数字编码参考
/phrases/i-love-you        → "I Love You" 短语页
/phrases/sos               → SOS 信号页
/tattoo-generator          → 纹身视觉化工具
/learn                     → 学习指南
/practice                  → 在线练习

/necklace                  → 项链推荐(affiliate)
```

## 导航设计
- **顶部导航**: Translator | Alphabet | Chart | Generator | Decoder | Audio | Learn
- **首页卡片**: 4个快速入口 → Translator / Alphabet / Audio / Practice
- **侧边栏**: Popular phrases (I love you / SOS / Hello)

## 技术选型
- 纯前端 Next.js 静态站
- 翻译/生成/解码逻辑: 纯 JS，无需后端
- 音频播放: Web Audio API
- 音频识别: 可选（高级功能，MVP可不做）
- 部署: Cloudflare Pages

## 变现路径
1. **广告** (主要): 工具页停留时间长，适合展示广告
2. **Affiliate** (补充): bracelet/necklace 页推荐 Amazon 商品
3. **PDF下载** (可选): chart 页提供高清 PDF 下载前插屏广告

## 与竞品的差异化
- morsecode.world (第一名): 功能全但**设计老旧**，无移动端优化
- 我们的优势:
  1. 现代化 UI + 暗色模式
  2. 音频功能突出（播放 + 未来可做音频识别）
  3. 纹身/首饰场景专门优化
  4. 完整的 SEO 内容矩阵（竞品只有工具页没有内容页）
  5. 多语言（后续可加）
